## Highlights
- When you run a program, the instructions make their way from the primary storage (your hard drive) to the CPU. ([View Highlight](https://read.readwise.io/read/01gv5dxd9p3wpy2wkjnxn0hh4t))
- In terms of priority of access, the L1 cache has the data the CPU is most likely to need while completing a certain task. ([View Highlight](https://read.readwise.io/read/01gv5e33dha15rst5dzjeqzba5))
- The L1 cache is usually split into two sections: the instruction cache and the data cache. The instruction cache deals with the information about the operation that the CPU must perform, while the data cache holds the data on which the operation is to be performed.
