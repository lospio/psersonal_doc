# 客户端驱动示例
#### python
```python
#!/usr/bin/env python3
import psycopg2

def main():
	try:
		cn_url = "postgres://192.168.223.161:5432/postgres?user=postgres&password=xxxxx"
		conn = psycopg2.connect(cn_url, connect_timeout = 2)
		sql = "select * from tt02_102038 ;"
		cur = conn.cursor()
		cur.execute(sql)
		row = cur.fetchone()
		print(row[0])
	except psycopg2.Error as e:
		print("get an errr :{0}".format(str(e)))
	conn.close();

if __name__ == '__main__':
	main()
```

# PG库迁移示例
## 导出
1. 导出定义语句，存入ddl.out
	```shell
	pg_dump -h localhost -p 5432 -U postgres -d test_db --quote-all-identifiers -C -s -F p   > ddl.out
	```
2. 导出数据,存入目录data_dir.out
	```shell
	pg_dump -h localhost -p 5432 -U postgres -d test_db  --quote-all-identifiers -a -F d  -f data_dir.out
	```
## 导入
1. 修改ddl.out中的数据库名称
	替换ddl.out **`create database`** 语句中的database名称(默认为postgres)为新库的名称（new_database).
2. 导入表定义
	```shell
	psql -h localhost -p 5432 -U postgres -f ddl.out
	```
3. 将test_db中的单机表转换为分布式表. 
	单个表的转换方式如下：
	```sql
	SELECT create_distributed_table('table_name','distributed_column')
	```
4. 导入数据
	```shell
	pg_restore -h localhost -p 5432 -U postgres -d new_database -F d -a data_dir.out
	```
# 多CN流量切换示例
多CN（一主多备）使用JDBC提供的机制实现流量切换.
如下多CN场景：
```yaml
CN主 : 192.168.60.1/5432
CN备 : 192.168.60.2/5433
```
配置JDBC URL实现自动流量切换：
```java
jdbc:postgresql://192.168.60.1:5432,192.168.60.2:5433/database
```
将两个CN的连接信息同时写入JDBC URL中，用逗号隔开。当发生故障无法连接某个CN节点时，驱动程序将尝试按顺序连接到它们中的每一个，直到连接成功。 如果没有成功，则抛出正常的连接异常。
